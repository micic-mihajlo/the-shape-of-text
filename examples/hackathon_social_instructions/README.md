# Hackathon Social Instructions

Original, general-purpose social-writing seed corpus for the Gemma 4 12B
instruction-tuned adapter run.

The examples are generated by `scripts/build_curated_social_instructions.py`
from generic product/workflow topics. They avoid scraped private posts, company
branding, protected identities, URLs, handles, and customer data.

Use this corpus for the quality run:

```bash
python scripts/validate_preflight.py \
  --train-file examples/hackathon_social_instructions/train.jsonl \
  --eval-file examples/hackathon_social_instructions/validation.jsonl
```

The completions are also checked by `scripts/check_generation_quality.py` before
training artifacts are uploaded.
